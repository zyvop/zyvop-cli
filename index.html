What the CLI does

A publishing workflow that fits your repository.

01

Markdown is the source

Set titles, tags, canonical URLs, cover images, categories, drafts, table of contents, and cross-post destinations in YAML frontmatter or override them with flags.

02

Keep site metadata intact

Use the same article files with Next.js, Astro, Hugo, Contentlayer, or another site generator. Unknown frontmatter keys are preserved in the developer-token payload.

03

Resolve relative images

Root-relative and file-relative covers and body images can use base_url, --base-url, or the origin of canonical_url.

04

Update repeat publishes

Stable canonical URLs, ZyVOP IDs, IDs, or slugs let supported destinations match existing articles instead of treating every run as a new post.

05

Preview without publishing

--dry-run validates and displays the normalized payload locally. It makes no network requests and does not require authentication.

06

Choose where credentials go

Use ZyVOP-managed integrations, or select --local to call provider APIs directly with credentials from your process environment.

07

Import existing articles

Bring articles into ZyVOP from Dev.to, Hashnode, Medium, or an RSS feed.

08

Automate from GitHub Actions

Run the CLI in your own workflow or use the reusable ZyVOP Publish Action to publish changed Markdown on push.

Command set

The tools you need; no dashboard detour.

zyvop publish <file>

Publish or update an article, set destinations, preview, draft, and tune metadata.

zyvop import <source> <id>

Import from Dev.to, Hashnode, Medium, or an RSS feed.

zyvop login

Sign in interactively or configure a ZyVOP token.

zyvop whoami

Check the authenticated account and connected endpoint.

zyvop logout

Clear locally stored ZyVOP credentials.

Private-runner mode

Provider secrets stay out of ZyVOP.

With --local, the CLI disables server-side cross-posting and sends each selected provider credential only to that provider. Supply credentials through environment variables or your CI secret store, never as command-line values.

export ZYVOP_TOKEN="…"
export ZYVOP_DEVTO_API_KEY="…"

zyvop publish ./posts/launch.md --local --devto
